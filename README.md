# Amit Mandal — Personal Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website content and structure
- `style.css` — responsive design and styling
- `script.js` — navigation, scroll effects and counters
- `assets/` — portrait, favicon and supplied resume

## Preview locally
Open `index.html` in a modern browser. For a local server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `YOURUSERNAME.github.io`.
2. Upload all files and folders from this project, keeping the folder structure.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. After deployment, visit `https://YOURUSERNAME.github.io`.

## Contact privacy
The phone number is not displayed anywhere on the website. The email address is not displayed as text; the Email me button opens the visitor's email application. LinkedIn is provided as the other contact option.

## Content accuracy
Employment dates and language proficiency levels were not supplied, so they are not invented. The resume download is the original uploaded DOCX file.
